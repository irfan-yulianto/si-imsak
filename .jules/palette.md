## 2026-10-22 - Replaced disabled attribute with aria-disabled on Buttons
**Learning:** In React components like Button, directly applying the native `disabled` attribute removes the element from the tab order and prevents native `title` tooltips from displaying. Furthermore, changing it to `aria-disabled` on a `<button type="submit">` will reactivate the browser's default behavior where pressing the "Enter" key within an input field submits the form using the first non-disabled submit button, which could bypass the button's intercepted `onClick` handler.
**Action:** When making a button accessible via `aria-disabled` to support tooltips and focus, remember to also intercept `onClick` to `e.preventDefault(); e.stopPropagation();`. Additionally, for `<button type="submit">`, ensure the form's `onSubmit` handler checks for the disabled state, or consider conditionally rendering the `type` attribute to avoid unintended form submissions via the Enter key.
