## 2025-06-20 - Clear Buttons for Search Inputs
**Learning:** Conditionally rendered clear buttons in React search inputs require explicit state-change triggers (filling the input) and wait conditions before Playwright locators can interact with them. Additionally, similar components (like `LocationSearch` and `MosqueFinder`) often share the exact same ARIA labels (e.g., "Hapus pencarian"), leading to strict mode violations in Playwright if not explicitly disambiguated with `.first` or `.last`.
**Action:** When adding clear buttons, always ensure adequate `pr-` padding on the input to avoid text overlap, always reset focus to the input via `previousElementSibling` upon clearing, and use highly specific locators or `.first` / `.last` when testing with Playwright to handle multiple identical elements on the same page.
