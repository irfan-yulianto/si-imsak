## 2024-07-16 - Add Clear Button to Search Inputs
**Learning:** Adding clear buttons to search inputs improves user experience by allowing them to quickly reset the input field. Also restoring focus to the input after clearing prevents users from having to click on the input again. Providing adequate right padding (`pr-9` instead of `pr-4`) ensures the text doesn't overlap the clear button.
**Action:** Always add clear buttons to search inputs and focus back on the input when cleared.
