## 2024-07-29 - Add clear buttons to search inputs
**Learning:** Users often need to clear the entire search query to restart their location or mosque search. A lack of a clear button forces repetitive keyboard deletes, hurting accessibility and efficiency. Adding an accessible clear button that correctly restores focus to the input drastically improves the search UX.
**Action:** When creating search inputs with state, proactively include a clear button with an `aria-label` that restores focus to the input via a `useRef` when clicked.
## 2024-03-24 - Accessible Empty States
**Learning:** Adding `role="status"` directly to `<li>` elements creates invalid ARIA nesting and overrides its implicit `listitem` role. Also, when dynamic searches yield zero results, silently hiding the dropdown instead of showing an explicit "not found" state is bad UX and leaves users confused.
**Action:** Always wrap the text inside the `<li>` with a `<span role="status" aria-live="polite">`. Ensure all dynamic search or filter functions in this application have explicit, accessible empty states (e.g., "Kota tidak ditemukan" or "Tidak ada masjid ditemukan") when yielding zero results, rather than silently hiding the UI.
