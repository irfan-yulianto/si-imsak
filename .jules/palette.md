## 2024-03-24 - Add Clear Search Button
**Learning:** Users often need to rapidly clear their search query to search for a new city. While they can press escape or backspace, a clear (X) button inside the input provides a more intuitive and accessible touch target, especially for mobile users.
**Action:** Always provide a clear button for search inputs that conditionally appears when the input is not empty, and ensure it correctly restores focus to the input when clicked.
