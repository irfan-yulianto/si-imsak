## 2026-10-20 - Ensure tooltips still show for disabled buttons
**Learning:** Native `disabled` attributes prevent hover events, which causes tooltips (like the `title` attribute) to not display on icon-only buttons when they are disabled. This makes it difficult for users to understand what the disabled button does.
**Action:** Replace the native `disabled` attribute with `aria-disabled="true"` on the `Button` component so it remains focusable and interactive enough to trigger the native tooltip. Handle the visual state via CSS (`aria-disabled:opacity-40` and `aria-disabled:cursor-not-allowed`) and manually intercept the click event in the `onClick` handler (`e.preventDefault(); e.stopPropagation();`) to maintain the functional disablement. Also ensure the tests assert on `aria-disabled` instead of using `toBeDisabled()`.
