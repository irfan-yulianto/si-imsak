## 2025-02-12 - Adding Clear Button Micro-UX to Search Inputs
**Learning:** For dynamic autocomplete search components like `LocationSearch.tsx` and `MosqueFinder.tsx`, users often find it cumbersome to manually backspace long queries. A conditionally rendered clear (X) button positioned over the input acts as a significant accessibility and usability enhancement. It's critical to ensure such absolute-positioned buttons don't block input text (by increasing the right padding of the input from `pr-4` to `pr-9`), are hidden during loading states to prevent overlaps with spinners, and cleanly restore focus back to the input after clicking for screen reader and keyboard continuity.
**Action:** Always consider the clear button pattern for input fields handling long strings or asynchronous autocomplete functionality. Ensure proper `<input>` padding, use `inputRef.current?.focus()` after clearing to maintain keyboard navigation, and assign a localized `aria-label` (e.g., "Hapus pencarian") for accessibility.
