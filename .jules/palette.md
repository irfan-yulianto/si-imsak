## 2025-05-19 - Added Clear Search functionality
**Learning:** React state-driven inputs often require explicit user affordances to clear them, especially since native HTML clear buttons (`type="search"`) are inconsistent across browsers and often un-styleable. Furthermore, clearing needs to gracefully restore focus back to the input to ensure a smooth keyboard experience, which can be tricky when using standard DOM traversal due to conditional button rendering.
**Action:** Always implement a dedicated `<button>` with an explicit 'Clear' or 'Bersihkan' ARIA label. When clicked, reset the React state and use a `ref` on the input element (`ref.current?.focus()`) to securely restore focus, rather than relying on `previousElementSibling`, which is brittle. Also ensure adequate padding on the input so text doesn't flow underneath the absolute positioned clear button.
