## 2024-08-20 - Add clear buttons to search inputs
**Learning:** Users often need to quickly clear search inputs to start a new search or reset the view. Providing a clear button that retains focus on the input significantly improves keyboard accessibility and general UX.
**Action:** Always include an accessible clear button with `type="button"`, an `aria-label`, and appropriate focus management in search inputs.
