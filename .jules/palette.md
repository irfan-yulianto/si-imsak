## 2024-05-19 - Clear Button in Search Inputs
**Learning:** Adding a clear button (X icon) to search inputs improves UX by allowing users to quickly clear their search queries. It is important to conditionally render this button only when there is input (or when not searching/loading, to prevent visual overlap), and to update the input's padding (e.g., changing `pr-4` to `pr-9`) so the text does not go under the button. Additionally, clicking the clear button should clear the query, hide the dropdown, and return focus to the input (`inputRef.current?.focus()`) so keyboard users don't lose their place.
**Action:** Use an `inputRef` to restore focus after clearing, use a standard clear icon SVG, and always adjust the input right padding to accommodate absolute positioned buttons. Ensure `aria-label` is present and localized.
