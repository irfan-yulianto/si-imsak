## 2024-XX-XX - Clear Buttons on Search Inputs
**Learning:** Found two search inputs (`LocationSearch.tsx` and `MosqueFinder.tsx`) that lack a way to quickly clear the input text. If a user types a long query, they have to manually backspace the entire string to clear it.
**Action:** Add an "X" (clear) button to search inputs when they contain text, improving the interaction experience by allowing instant clearing and fast refocusing.
