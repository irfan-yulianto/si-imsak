## 2026-11-02 - Accessible Disabled Buttons and Icon Tooltips
**Learning:** Native `disabled` attributes on buttons prevent screen readers from focusing them, hiding their `title` tooltips and making their disabled state undiscoverable. Changing to `aria-disabled="true"` preserves focus and native tooltips, but requires intercepting clicks in React and replacing `.toBeDisabled()` / `.toBeEnabled()` test assertions with `.toHaveAttribute("aria-disabled", "true")` or `.not.toHaveAttribute("aria-disabled", "true")`.
**Action:** When implementing disabled states for interactive elements (especially icon buttons needing tooltips), prefer `aria-disabled` combined with CSS styling and click interception. Always audit and update associated test files to check for the ARIA attribute rather than the native state.
