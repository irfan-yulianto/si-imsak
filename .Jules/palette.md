## 2024-05-19 - Adding clear button for search inputs
**Learning:** For a search input component (like `LocationSearch.tsx` and `MosqueFinder.tsx`), having a clear button makes it easier for users to clear their query and enter a new one. It's important to provide a right padding to avoid overlapping the clear button with the text. The clear button should also be keyboard accessible. I need to make sure the focus returns to the input field after it's clicked. It's critical to make sure the clear button handles focus gracefully so screen readers and keyboard users can clear their input and continue typing.
**Action:** When adding clear buttons, always include `pr-9` padding (or more) on the input, use the existing XIcon, ensure it receives keyboard focus, has an appropriate ARIA label ("Hapus pencarian"), and explicitly returns focus back to the input element via a React `useRef` when activated.
