## 2024-06-28 - Add clear button to location search
**Learning:** When adding conditional clear buttons to search inputs, it's crucial to consider three things for accessibility and UX: 1) the input needs adequate right padding to prevent text overlapping with the button, 2) the button should be hidden during loading states to prevent layout collisions with loading spinners, and 3) we must use a React ref to restore focus back to the input after clearing it, so users can immediately type a new query without having to click the input again. Also, ARIA labels must be localized to the application's primary language (e.g., "Hapus pencarian" instead of "Clear search").
**Action:** When implementing clear buttons on inputs in this design system, always add `pr-9` (or similar padding) to the input, conditionally render the clear button (e.g., `query.length > 0 && !isSearching`), use an `inputRef` to restore focus (`inputRef.current?.focus()`), and provide localized ARIA labels.
